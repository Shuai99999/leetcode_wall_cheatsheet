# LeetCode 语法速查手册

一个可搜索、可筛选语言列、可打印成 A4 PDF 的 React 速查手册。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 导出 PDF

打开网页后点击右上角“导出 PDF”，在浏览器打印窗口中选择“另存为 PDF”。推荐纸张设为 A4、缩放 100%，并开启背景图形。

## GitHub Pages

项目通过 GitHub Actions 自动发布。推送到 `main` 分支后，工作流会安装依赖、构建 `dist` 并部署到：
